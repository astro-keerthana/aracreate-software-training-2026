# Day 02 - Client requirements

## 10 steps to writing good software requirments
01. Identify stakeholders and gather input
02. Define the problem
03. Outline high-level features and functionalities
04. Create specific, auctionable requirements
05. Prioritize requirements
06. Review requirements with stakeholder
07. Refine and clarify based on feedback
08. Document assumptions and constraints 
09. Include relevant diagram or mockups
10. Establish a process for managing requirement changes
