# Day 03 - User Stories

## User roles
Space Enthusiast 
. Want a clear menu with expandable categories, so that can quickly find topics.
. Want to see featuered stories with reading time and publish age on the homepage, so that can pick what to read based on how much time have.
. Want to see the current big mission event with a video at the top of the homepage, so that immediately know what NASA is doing right now.

Student
. Want an A-Z list of missions, so that can easily find information about a specific mission for the assignment.

Educator, Journalist
. Want to search the site and see popular suggested searches, so that can find content even when don't know exactly what to type.
. Interested in Earth Science, want a highlights section for the topic, so that can see the latest news in area of interest without searching.
. Want a "Recently Published" page, so that can catch up on everything new since last visit.
