# UI/UX Design Principles
1. Hierarchy - Font size and weight, Contrast, Spacing
2. Progressive disclosure -> Providing right amount of information
3. Consistency -> Familiar from the first click
4. Contrast -> Draw attention to important content or features
5. Accessibility -> Carefully contrast colors and luminosity to make designs distinctive and more accessible to users with vision impairments
6. Proximity -> Things that belong together should stay together.
7. Alignment -> Clean lines make designs feel professional. 

## Benefits of applying UI design principles
. Enhances usability
. Increases efficiency
. Improves decision-making
. Decreases cognitive load
